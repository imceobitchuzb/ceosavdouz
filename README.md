# CEOSAVDOUZ (Узбекистан) — Платформа управления бизнесом и торговлей

**CEOSAVDOUZ** — премиальная, полнофункциональная SaaS-платформа для автоматизации малого и среднего бизнеса в Узбекистане. Платформа объединяет продажи, складской учет, контроль дебиторской задолженности («насия»), кассу, доходы/расходы и глубокую бизнес-аналитику в национальной валюте Узбекистана — **узбекских сумах (UZS)**.

---

## 🎯 Ключевые возможности

1. **Каталог товаров и умный склад:**
   - Ведение артикулов (SKU), штрихкодов, категорий, себестоимости и розничных цен в UZS.
   - Единицы измерения: штуки, килограммы, метры, пачки, комплекты, литры.
   - Автоматический расчет торговой наценки и маржинальности.
   - Оповещения о снижении остатков ниже порогового минимума.

2. **Оформление заказов и Касса (POS):**
   - Быстрый выбор товаров со склада с моментальной проверкой доступного количества.
   - Привязка к существующему контрагенту или создание нового покупателя в 1 клик.
   - Учет скидок, частичных оплат и различных способов расчетов: Наличные, Uzcard / Humo, Банковский перевод (р/с).
   - Автоматическое списание проданного товара со склада в транзакции.
   - Корректная обработка отмены заказа: автоматический возврат остатков на склад и сторнирование задолженности.

3. **База клиентов и учет долгов (Насия):**
   - Учет номеров телефонов операторов Узбекистана (+998).
   - Фиксация баланса дебиторской задолженности по каждому клиенту.
   - Прием частичных платежей в счет погашения долга с автоматическим пересчетом и отражением в кассовом притоке.
   - Защита от отрицательных балансов.

4. **Финансы, Cash Flow и учет расходов:**
   - Фиксация операционных расходов (аренда, заработная плата, закупки, логистика Fargo/BTS, маркетинг).
   - Четкое разделение выручки от заказов и прочих притоков без задвоения сумм.
   - Расчет реального чистого финансового результата (Прибыль / Убыток).

5. **Бизнес-аналитика и отчетность:**
   - Наглядные интерактивные графики выручки (Recharts Area Chart).
   - Сравнительные столбчатые диаграммы доходов и расходов.
   - Топ товаров по фактической выручке и объему реализации.
   - Средний чек (AOV), торговая маржа в процентах и структура товарных категорий.

6. **Команда и разграничение прав:**
   - 4 системные роли: **Владелец (OWNER)**, **Администратор (ADMIN)**, **Менеджер продаж (MANAGER)**, **Кассир (CASHIER)**.
   - Серверная авторизация: кассир не видит себестоимость и общую финансовую аналитику.
   - Возможность создания учетных записей сотрудников с прямым входом.

7. **Локализация и региональная специфика:**
   - Валюта: узбекский сум (UZS) с форматированием (например, `12 500 000 сум`).
   - Часовой пояс: `Asia/Tashkent` (UTC+5).
   - Интерфейс на русском языке с подготовленной архитектурой под узбекскую латиницу (O'zbekcha).

8. **Архитектурный шлюз Telegram-бота (Этап 2):**
   - Серверный контракт `TelegramNotificationService` в `src/lib/services/telegram-stub.ts`.
   - Полная готовность к интеграции с отдельным микросервисом на Python 3.11+ / `aiogram 3.x` через защищенные вебхуки (HMAC SHA-256).

## 🛠 Технологический стек

- **Фреймворк:** Next.js 14 (App Router, Server Components & Server Actions/API)
- **Язык:** TypeScript 5 (строгая типизация)
- **Стилизация:** Tailwind CSS 3, дизайн-система в теплых светлых тонах с глубоким изумрудным акцентом (`#047857`)
- **База данных:** Relational Database via Prisma ORM 5
  - *Для локальной разработки:* SQLite (`file:./dev.db`) для мгновенного запуска без внешних сервисов
  - *Для продакшена:* PostgreSQL с полной схемой, транзакциями и внешними ключами
- **Аутентификация:** `jose` (JWT HTTP-only cookies) + `bcryptjs` (хеширование паролей)
- **Валидация:** Zod 3
- **Графики:** Recharts 2
- **Иконки:** Lucide React

## 🚀 Быстрый старт локально

### 1. Предварительные требования
- Node.js v20+
- npm v10+

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
По умолчанию в `.env` настроена локальная база данных SQLite (`file:./dev.db`), не требующая установки дополнительных серверов:
```env
DATABASE_URL="file:./dev.db"
JWT_SECRET="ceosavdouz_local_dev_jwt_secret_key_998_uzb_tashkent"
NODE_ENV="development"
NEXT_PUBLIC_APP_URL="http://localhost:3000"
```

### 4. Инициализация базы данных и сидинг
Сгенерируйте клиент Prisma, примените схему и наполните реалистичными данными:
```bash
npx prisma generate
npx prisma db push
node prisma/seed.js
```

### 5. Запуск сервера разработки
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 🐘 Развертывание с PostgreSQL (Production)

Для развертывания в рабочей среде с PostgreSQL:
1. В `prisma/schema.prisma` замените:
   ```prisma
   datasource db {
     provider = "postgresql"
     url      = env("DATABASE_URL")
   }
   ```
2. В файле `.env` укажите реальную строку подключения к PostgreSQL:
   ```env
   DATABASE_URL="postgresql://user:password@db-host:5432/ceosavdouz?schema=public"
   ```
3. Выполните синхронизацию схемы:
   ```bash
   npx prisma db push
   # или npx prisma migrate deploy
   ```

## 🤖 Архитектура Telegram-бота (Этап 2)

В кодовой базе предусмотрен серверный сервис `src/lib/services/telegram-stub.ts`, реализующий контракт для отправки:
- Уведомлений о поступивших заказах;
- Сигналов о критически низком остатке товаров на складе;
- Ежедневных итоговых сводок для владельца бизнеса.

Для подключения реального бота на базе `aiogram`:
1. Создайте бота в Telegram через `@BotFather`.
2. Укажите полученный токен в `.env`:
   ```env
   TELEGRAM_BOT_TOKEN="123456789:ABCdefGHIjklMNOpqrSTUvwxYZ"
   TELEGRAM_WEBHOOK_SECRET="your_secure_secret"
   ```
3. Сервис автоматически определит наличие конфигурации и начнет трансляцию событий.
